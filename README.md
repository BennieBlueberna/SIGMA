# SIGMA
SIGMA (Sistema Integrado Gráfico de Monitoreo de Asistencia) es una solución tecnológica web diseñada para la gestión, control y supervisión en tiempo real del acceso de estudiantes y personal en entornos educativos. La plataforma integra hardware IoT (dispositivos ESP32-CAM) con un panel de control intuitivo para automatizar el registro biométrico
